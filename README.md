# 👾 外星人入侵 · 保衛石門 Alien Invasion

> 桃園市龍潭區**石門國民小學**專屬的復古風太空射擊遊戲 —— 駕駛戰機，擊退一波波外星艦隊，守住石門上空！

🌐 **線上使用：[外星人入侵·保衛石門 — 復古太空射擊 × 全校排行榜](https://cagoooo.github.io/alien-invasion/)**

> 📌 **目前版本：v1.7.0**（依據 程式內版本常數）

純 **HTML5 Canvas + 原生 JavaScript** 打造，**單一檔案、零相依、零建置**。任何瀏覽器打開即玩，電腦與手機都支援。

## 🎮 怎麼玩

| 平台 | 操作 |
|---|---|
| 💻 電腦 | `←` `→` 或 `A` `D` 移動（**自動開火**）· `P` 暫停 · `M` 靜音 · `Enter` 開始／重來 |
| 📱 手機 | 手指在畫面上**滑動**操控戰機 |

## ✨ 特色

- **三種難度**：簡單（5 命）／普通（3 命）／困難（2 命），同一間教室不同程度的孩子都玩得起來
- **三種外星人**：偵察兵、戰鬥機、轟炸機，經典「整隊橫移＋越打越快」手感
- **王關 Boss**：每 5 波出現巨型母艦，三種彈幕型態 + 血條
- **道具系統**：火力強化、急速射擊、能量護盾、增加戰機
- **連擊加成**：連續擊殺不失誤 → 分數倍率提升
- **名人堂 TOP 5**：本機排行榜，可留暱稱
- **特效**：星空視差背景、爆炸粒子、引擎尾焰、螢幕震動、Web Audio 合成音效
- **石門主題**：開場校徽、「保衛石門」劇情字卡

## 🚀 本地執行

直接用瀏覽器開啟 `index.html` 即可；或啟動內附的小型靜態伺服器：

```bash
node server.js   # → http://localhost:5050
```
